## What's new
- **New license.** From this release on, OpSkills is open source under [AGPL-3.0-only](https://github.com/opskills-app/opskills/blob/v0.11.0/LICENSE). It's still free to use, change and run for your own team, and your runbooks, scripts and API integrations aren't covered by it. If you run a **modified** version for other people over a network, you must offer them the source code of your version.
- **Earlier releases keep their license.** Versions up to and including 0.10.0 were released under the Apache License 2.0 and stay available under it.
- **Source code link.** The sign-in page and the sidebar (the bottom of each page on phones) link to the source of the exact version you're running. `GET /api/v1/system` now also returns `license` and `source_url`. If you run a modified version for others, point `SOURCE_URL` in `server/src/main.rs` at your own source.
- **Contributor License Agreement.** Before a first pull request is merged, contributors agree to the [CLA](https://github.com/opskills-app/opskills/blob/v0.11.0/CLA.md) by posting one comment. Contributors keep the copyright to their work.
- **Commercial license.** The maintainers can also license OpSkills under separate commercial terms, for use without the AGPL's obligations.

No other behavior changed.

## Upgrading from v0.10.0
- **Docker:** pull `opskills/opskills:0.11.0` and re-create the container with the same volume.
- **Debian/Ubuntu server:** install the new `opskills_0.11.0_*.deb`. Your config file is kept.
- **Agents:** no change needed. Upgrading them is optional.

## Install the server

**Docker** (`linux/amd64`, `linux/arm64`):

```bash
docker run -d --name opskills -p 127.0.0.1:8080:8080 \
  -v opskills-data:/var/lib/opskills --restart unless-stopped \
  opskills/opskills:0.11.0
docker logs opskills 2>&1 | grep 'Admin password'
```

**Debian 12+ / Ubuntu 22.04+:**

```bash
curl -LO https://github.com/opskills-app/opskills/releases/download/v0.11.0/opskills_0.11.0_amd64.deb
curl -LO https://github.com/opskills-app/opskills/releases/download/v0.11.0/SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
sudo apt install ./opskills_0.11.0_amd64.deb
sudo systemctl start opskills
sudo journalctl -u opskills | grep 'Admin password'
```
