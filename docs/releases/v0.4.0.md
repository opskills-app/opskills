Runbooks that ask for inputs, retry, handle failures, copy files and call each other.

## What's new
- **Inputs.** A runbook can ask for values when someone starts it: text (with an optional pattern), number, yes or no, choice, and secret. Pressing **Run** opens a form; the run page shows the values used, with secret ones masked and never stored. **Run again** fills in the last values.
- **Run values in commands.** `{{ inputs.service }}`, `{{ host.name }}`, `{{ run.id }}` and friends become single, quoted shell words, so a value can never run as a command. Every input is also `$OPSKILLS_INPUT_<NAME>`, and each step gets `$OPSKILLS_HOST_NAME`, `$OPSKILLS_RUNBOOK_NAME` and more.
- **Copy a file.** A step can write a file on its host from text (with run values filled in) or from a vault secret, with a file mode. The file is written in full, then moved into place.
- **Call another runbook.** A step can run another runbook on the same host and wait for it, passing inputs. Cancel and timeouts reach the called run, and the two runs link to each other.
- **Retries and failure handling.** Per step: timeout, retries with a wait between tries, and continue on error. Per runbook: stop at the first failure, or run the remaining steps and then fail. Durations accept `90s`, `10m` or `1h30m`.
- **Output limit.** A runbook can keep fewer lines and either drop further output or stop the run.

The full guide is [Writing runbooks](https://github.com/opskills-app/opskills/blob/v0.4.0/docs/runbooks.md).

## Upgrading from v0.3.1
- **Docker:** pull `opskills/opskills:0.4.0` and re-create the container with the same volume. Existing runbooks and runs load unchanged.
- **Debian/Ubuntu server:** install the new `opskills_0.4.0_*.deb`.
- **Agents:** optional. Agents on 0.3.x keep working. Upgrade them so a host keeps a run's working folder when a retry or a later step comes after a failed step; older agents remove it after any failure.

## Install the server

**Docker** (`linux/amd64`, `linux/arm64`):

```bash
docker run -d --name opskills -p 127.0.0.1:8080:8080 \
  -v opskills-data:/var/lib/opskills --restart unless-stopped \
  opskills/opskills:0.4.0
docker logs opskills 2>&1 | grep 'Admin password'
```

**Debian 12+ / Ubuntu 22.04+:**

```bash
curl -LO https://github.com/opskills-app/opskills/releases/download/v0.4.0/opskills_0.4.0_amd64.deb
curl -LO https://github.com/opskills-app/opskills/releases/download/v0.4.0/SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
sudo apt install ./opskills_0.4.0_amd64.deb
sudo systemctl start opskills
sudo journalctl -u opskills | grep 'Admin password'
```
