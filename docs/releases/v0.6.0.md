Pick hosts with a filter, and retry just the hosts that didn't finish.

## What's new
- **Host filters.** Under **Run on**, a filter like `tags:web !name:db-*` or `os:rocky* arch:amd64` picks every host it matches when a run starts, including hosts enrolled later. Terms use `tags`, `name`, `hostname`, `os` and `arch`, with `*` wildcards, `!` to exclude and commas for "any of". The editor shows which hosts match as you type, and a filter combines with hosts and tags you pick by hand.
- **Retry failed hosts.** When a run ends with hosts that failed, or were skipped or cancelled because of a failure, its page offers **Retry N hosts**. That runs the runbook again on just those hosts with the same inputs (secret inputs are asked for again), using the runbook as it is now, so you can fix a step first. The new run links back to the one it retries.
- **API:** `GET /api/v1/hosts?filter=...` previews a filter, and `POST /api/v1/runs/{id}/retry` retries a run.

See [Choosing hosts with a filter](https://github.com/opskills-app/opskills/blob/v0.6.0/docs/runbooks.md#choosing-hosts-with-a-filter) and [Retrying hosts that didn't finish](https://github.com/opskills-app/opskills/blob/v0.6.0/docs/runbooks.md#retrying-hosts-that-didnt-finish).

## Upgrading from v0.5.0
- **Docker:** pull `opskills/opskills:0.6.0` and re-create the container with the same volume. Existing runbooks load unchanged.
- **Debian/Ubuntu server:** install the new `opskills_0.6.0_*.deb`.
- **Agents:** no change needed.

## Install the server

**Docker** (`linux/amd64`, `linux/arm64`):

```bash
docker run -d --name opskills -p 127.0.0.1:8080:8080 \
  -v opskills-data:/var/lib/opskills --restart unless-stopped \
  opskills/opskills:0.6.0
docker logs opskills 2>&1 | grep 'Admin password'
```

**Debian 12+ / Ubuntu 22.04+:**

```bash
curl -LO https://github.com/opskills-app/opskills/releases/download/v0.6.0/opskills_0.6.0_amd64.deb
curl -LO https://github.com/opskills-app/opskills/releases/download/v0.6.0/SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
sudo apt install ./opskills_0.6.0_amd64.deb
sudo systemctl start opskills
sudo journalctl -u opskills | grep 'Admin password'
```
