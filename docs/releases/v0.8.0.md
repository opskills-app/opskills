Scheduled runs: run a runbook on repeat, or once at a set time.

## What's new
- **Repeating schedules.** Under **Schedules** in the runbook editor, pick a preset (every 15 minutes, hourly, daily at 03:00, weekdays at 09:00, Mondays at 06:00) or write a 5-field cron expression, and choose the time zone it runs in. Times follow daylight saving, so `0 3 * * *` is 03:00 local all year. The editor shows the next times as you type.
- **One-time runs.** Pick a date and time; the schedule runs once and then shows as done.
- **Inputs per schedule.** Each schedule gives values for the runbook's inputs. Secret inputs can't be stored in a schedule.
- **Safe to restart.** Each time fires once, even across restarts. Times missed while the server was down are skipped, not replayed, and a scheduler that falls behind starts one run, not a burst.
- **Visible.** The runbook page lists each schedule with its next run, a link to the last run it started, and why the last attempt couldn't start, if it couldn't. Scheduled runs show `schedule <name>` as who started them.
- **API:** schedules are part of the runbook. `GET /api/v1/runbooks/{id}/schedules` shows next times and last results, and `POST /api/v1/schedules/preview` previews a cron expression.

See [Schedules](https://github.com/opskills-app/opskills/blob/v0.8.0/docs/runbooks.md#schedules).

## Upgrading from v0.7.0
- **Docker:** pull `opskills/opskills:0.8.0` and re-create the container with the same volume. Existing runbooks have no schedules until you add them.
- **Debian/Ubuntu server:** install the new `opskills_0.8.0_*.deb`.
- **Agents:** no change needed.

## Install the server

**Docker** (`linux/amd64`, `linux/arm64`):

```bash
docker run -d --name opskills -p 127.0.0.1:8080:8080 \
  -v opskills-data:/var/lib/opskills --restart unless-stopped \
  opskills/opskills:0.8.0
docker logs opskills 2>&1 | grep 'Admin password'
```

**Debian 12+ / Ubuntu 22.04+:**

```bash
curl -LO https://github.com/opskills-app/opskills/releases/download/v0.8.0/opskills_0.8.0_amd64.deb
curl -LO https://github.com/opskills-app/opskills/releases/download/v0.8.0/SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
sudo apt install ./opskills_0.8.0_amd64.deb
sudo systemctl start opskills
sudo journalctl -u opskills | grep 'Admin password'
```
