Audit log: see who changed what, and when.

## What's new
- **Audit log.** Every change is recorded: sign-ins and failed sign-ins, password changes, users and roles, API tokens, runbooks, runs started, retried and cancelled, webhooks, vault secrets, hosts and email settings. Reading isn't recorded, and secret values never appear, only secret names.
- **Who and how.** Each event names the user, and how they did it: directly, through an API token (`token ci`), or the server on behalf of a schedule, webhook or agent (`system` via `schedule nightly`, `webhook deploy`, `agent web-1`).
- **Audit log page** for admins: newest first, search across people, runbooks, hosts and notes, narrow it to an area (sign-ins, users, API tokens, runbooks, runs, webhooks, vault, hosts, settings), and load older events. Runbooks and runs link to their pages.
- **Retention.** Events are kept for up to 90 days. To keep less, set `audit.retention_days` (1 to 90; `OPSKILLS_AUDIT__RETENTION_DAYS`); older events are removed every hour.
- **API:** `GET /audit` with `q`, `action`, `actor`, `limit` and `before` (admins, also with an admin's API token).

See [Audit log](https://github.com/opskills-app/opskills/blob/v0.13.0/docs/audit.md).

## Upgrading from v0.12.0
- **Docker:** pull `opskills/opskills:0.13.0` and re-create the container with the same volume.
- **Debian/Ubuntu server:** install the new `opskills_0.13.0_*.deb`. Your config file is kept; to keep the log for less than 90 days, add an `[audit]` section with `retention_days` (the new default file shows it).
- **Agents:** no change needed.
- The log starts with this version: changes made before the upgrade aren't in it.

## Install the server

**Docker** (`linux/amd64`, `linux/arm64`):

```bash
docker run -d --name opskills -p 127.0.0.1:8080:8080 \
  -v opskills-data:/var/lib/opskills --restart unless-stopped \
  opskills/opskills:0.13.0
docker logs opskills 2>&1 | grep 'Admin password'
```

**Debian 12+ / Ubuntu 22.04+:**

```bash
curl -LO https://github.com/opskills-app/opskills/releases/download/v0.13.0/opskills_0.13.0_amd64.deb
curl -LO https://github.com/opskills-app/opskills/releases/download/v0.13.0/SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
sudo apt install ./opskills_0.13.0_amd64.deb
sudo systemctl start opskills
sudo journalctl -u opskills | grep 'Admin password'
```
