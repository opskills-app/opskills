Inbound webhooks: let CI, GitHub or any other system start a runbook with an HTTP request.

## What's new
- **Webhooks.** On a runbook's page, **New** under **Webhooks** makes a secret URL. A `POST` to it with a JSON body starts a run, with no sign-in. The URL is shown once and only a hash of its secret is stored; **New URL** replaces it, and the old one stops working at once.
- **Inputs from the payload.** Map each runbook input to a dotted path in the body, like `repository.name` or `commits.0.id`. Values are checked like any other run's inputs and expand quoted in commands.
- **Signed calls.** Turn on **Require a signature** and calls must carry the HMAC-SHA256 of the body in `X-OpSkills-Signature: sha256=...`. GitHub's `X-Hub-Signature-256` works too, so a GitHub repository webhook can call OpSkills directly. The signing secret is shown once and kept encrypted with the vault key.
- **See what happened.** The runbook page shows each webhook's last call: the run it started, or why it didn't. The last 20 calls are kept. Runs show `webhook <name>` as who started them.
- The dialog shows a ready-to-paste `curl` example, with the signature worked out by `openssl`.
- **API:** `GET`/`POST /api/v1/runbooks/{id}/webhooks`, `PUT`/`DELETE /api/v1/webhooks/{id}`, `POST /api/v1/webhooks/{id}/rotate`, and `POST /api/v1/hooks/{token}` for callers.

See [Webhooks](https://github.com/opskills-app/opskills/blob/v0.9.0/docs/runbooks.md#webhooks).

## Upgrading from v0.8.0
- **Docker:** pull `opskills/opskills:0.9.0` and re-create the container with the same volume. Nothing changes until you add a webhook.
- **Debian/Ubuntu server:** install the new `opskills_0.9.0_*.deb`.
- **Agents:** no change needed.
- If OpSkills sits behind a proxy that only lets your own network in, allow `/api/v1/hooks/` from the systems that will call it.

## Install the server

**Docker** (`linux/amd64`, `linux/arm64`):

```bash
docker run -d --name opskills -p 127.0.0.1:8080:8080 \
  -v opskills-data:/var/lib/opskills --restart unless-stopped \
  opskills/opskills:0.9.0
docker logs opskills 2>&1 | grep 'Admin password'
```

**Debian 12+ / Ubuntu 22.04+:**

```bash
curl -LO https://github.com/opskills-app/opskills/releases/download/v0.9.0/opskills_0.9.0_amd64.deb
curl -LO https://github.com/opskills-app/opskills/releases/download/v0.9.0/SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
sudo apt install ./opskills_0.9.0_amd64.deb
sudo systemctl start opskills
sudo journalctl -u opskills | grep 'Admin password'
```
