Safe rollouts: run on your hosts one by one, in parallel, or in batches, canary first.

## What's new
- **Rollout modes.** A runbook that runs on hosts can take them one by one (as before), all at once or up to a limit you set, or in batches of a number of hosts or a percentage like 25%.
- **Canary first.** Run one or more hosts on their own before any other host starts.
- **Pauses.** Wait a set time after the canary and between batches, like `30s` or `5m`.
- **When a host fails.** Choose whether hosts that haven't started are skipped or still run. Hosts already running always finish, and the run ends as failed either way. By default this follows the runbook's "when a step fails" setting, so existing runbooks behave as before.
- **Clear run logs.** Each wave is announced in the output, like `Canary: web-1` and `Batch 2 of 3: web-5, web-6, web-7`.

Set it in the editor's new **Rollout** card, shown when a runbook runs on hosts, or with `rollout` in the API. See [Running on several hosts](https://github.com/opskills-app/opskills/blob/v0.5.0/docs/runbooks.md#running-on-several-hosts).

## Upgrading from v0.4.0
- **Docker:** pull `opskills/opskills:0.5.0` and re-create the container with the same volume. Existing runbooks keep running one host at a time.
- **Debian/Ubuntu server:** install the new `opskills_0.5.0_*.deb`.
- **Agents:** no change needed; agents on 0.3.x and 0.4.x keep working.

## Install the server

**Docker** (`linux/amd64`, `linux/arm64`):

```bash
docker run -d --name opskills -p 127.0.0.1:8080:8080 \
  -v opskills-data:/var/lib/opskills --restart unless-stopped \
  opskills/opskills:0.5.0
docker logs opskills 2>&1 | grep 'Admin password'
```

**Debian 12+ / Ubuntu 22.04+:**

```bash
curl -LO https://github.com/opskills-app/opskills/releases/download/v0.5.0/opskills_0.5.0_amd64.deb
curl -LO https://github.com/opskills-app/opskills/releases/download/v0.5.0/SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
sudo apt install ./opskills_0.5.0_amd64.deb
sudo systemctl start opskills
sudo journalctl -u opskills | grep 'Admin password'
```
